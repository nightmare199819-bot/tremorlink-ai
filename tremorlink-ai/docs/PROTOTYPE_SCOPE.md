# Prototype scope and limitations

## Included

This prototype is a user-interface and interaction demonstration. Scenario selection updates the dashboard, sensor visualization, classifier presentation, network availability, event verification, and activity feed. Community reports can be added during the current browser session.

## Simulated

- Accelerometer-like waveform and signal features.
- Model classification labels and confidence values.
- Device availability and mesh topology.
- Packet forwarding and duplicate handling.
- Independent-origin quorum counts.
- Community report stream.

## Not implemented

- Real phone sensors or background sensor collection.
- Real Bluetooth, Wi-Fi Direct, LoRa, or other peer-to-peer radio communication.
- A trained or validated earthquake detection model.
- Geolocation, emergency-service integration, or public alert delivery.
- Backend persistence, user accounts, or multi-user synchronization.

## Safety

The interface is for development and demonstration only. It must not be represented as a certified warning system or used to make safety decisions.
